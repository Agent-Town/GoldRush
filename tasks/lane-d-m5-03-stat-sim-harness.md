## The gap (spec slice 03)
The paper validator (slice 01) checks an item's DECLARED stats against the stat-budget on paper. It cannot catch an item whose declared stats pass but whose ACTUAL in-sim effect over-performs (the abuse case). Slice 03 = a headless empirical validator that RUNS the item in seeded scripted sim windows and measures real delta.
