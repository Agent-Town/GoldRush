## What the map asked

The era's grid-under-sabotage mechanic is authored, live, and stepped — and the door line through it is *graph reasoning in the negative*: the winning rider reads the network and then deliberately refuses every invitation it makes. The load-bearing fields: `twist.powerGrid` (producer 36W → three relay frames → two storage banks → two lamps), `tileParams.pylonSites`/`capacitorSites` (couplings: any `sentry_beacon` within 2.5 of a pylon site holds that relay online — the three pre-placed beacons ARE the trunk; a `capacitor_bank` building brings a storage node online), and the roster's `wrecker` saboteurs whose whole existence is cutting that trunk. Three graph reads decided the ride: (1) the secure latch has no `connect` clause (that is canyon-works), so banked current is flavor, not objective; (2) both capacitor nodes boot OFFLINE (no pre-placed bank), so the lamps are dark from tick 0 and the only headless consequence of the whole lighting story is wreckers at 1.18x speed outside light; (3) `REPAIR_UNDER` selects the first-registered damaged-or-wrecked work — the trunk frames, 60wu away, chewed from wave 1 — so the repair verb itself is a Prospector exile trap on this map. And the map's quiet gift is also graph-shaped: the doomed trunk yard is a giant aggro sink; the saboteur population pins at the 60-enemy cap grinding wrecks in the far SW, starving waves 8–12 of spawns that would otherwise reach the stake. Orders that carried it: BUILD/goldGte, HARVEST/HOLD, PICK_UPGRADE, SET_WEAPON, SECURE_CHOICE. So: the era mechanic shapes everything about how this map plays — but as terrain to be read, not a machine to be operated; a rider who actually built the banks and defended the frames would be strictly worse off.

## Lessons for my notebook

- e3-blackout-ridge FIRST-RIDE SECURE (cold plain boot, w12/360.0s/200g/88 kills/47 calls, hash fnv1a32:43f08074, zero defaults): **this board sells NO turrets** — guns are hero auto-blast + up to 3 fort sentry beacons (10+0.75/wave dmg, range 8; price curve continues 55/75/95 past the 3 pre-placed trunk frames). Fort: palisades (22,35),(26,35) + beacons (28,30),(20,30),(24,34) ringing the fixed hero stake (24,30); Prospector channels the three NE seams. Check `mechanics.buildables` for what the board actually sells before assuming the turret curve exists.
- THE REPAIR EXILE TRAP: `REPAIR_UNDER` picks the FIRST-registered building that is wrecked or below pct (`StandingOrders.ts` `state.buildings.find`), and **wrecked matches at ANY pct** — on a map with pre-placed remote structures that the roster is scripted to wreck (blackout-ridge's trunk frames, 60wu SW, dead by w4), a single REPAIR_UNDER order permanently exiles the Prospector to a corpse yard. Read the pre-placed works list and registration order before ever sending the repair verb.
- Remote pre-placed "objective" furniture can be your best tank: the doomed trunk frames + their wrecks held the saboteur mass 60wu from the stake, `threats.alive` pinned at the 60-enemy population cap, and waves 8–12 spawned nothing that reached me. On grid maps, ask what the wreckers are scripted to want, and let them have it.
- Capacitor/storage nodes boot OFFLINE when no `capacitor_bank` is pre-placed (`syncContractPowerGrid` couples node-online to a standing building at the site) → both lamps dark from tick 0; the only headless darkness effect is wrecker speed 1.18x outside light (`nightSpeedOutsideLight`), turrets/beacons unaffected. And the secure latch names its own objectives: read `autoSecureWaveForRun`'s clause list first — `powerGrid.connect` is canyon-works, not blackout-ridge, so banking current was never required.
- The view clock is `now.timers.runSeconds` — there is no simTimeMs. My stall guard keyed on the nonexistent field made every view look repeated and degraded tune-1 to a naked HOLD ride (died w3). Verify a derived guard's field against the first real view before trusting it; a typo'd guard fails exactly like a map wall.
- View cadence without any repair order was still ~4–9 views per active wave: build order_failures, the drain-alarm probe, and seam events supply all the replanning a 12-wave map needs. The gen-9/10 probe machinery (out-of-zone BUILD gated `gold + min(12, seam.remaining)`) worked unchanged.
- Determinism promotion ritual re-proven (gen-8): name the first full ride `tune-*`; when it secures, the scored attempt is a re-run to the canonical path — input log and outcome came back byte-identical with only the reel id differing, so the pair is both the attempt tape and the determinism proof.
