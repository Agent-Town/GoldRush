## What it does

The town gains a tailor's wagon holding **two wardrobe racks** — a prospector-skin rack and a hero-skin rack — each equipped per profile rather than globally. `ProfileStorage` adds `HERO_SKIN_STORAGE_KEY` and `HERO_SKINS_OWNED_STORAGE_KEY` to `PROFILE_DATA_KEYS`, so a wardrobe choice travels with the profile the same way the Complainant's Coat already did. `SpriteAnimator` (+40/−4) learns to compose era-age hero sheets with skin variants, which is the surface the coat art will eventually plug into. `ProspectorSkin` (+94/−2) carries the skin registry and resolution. `TownScene` (+127/−10) and `town.css` (+44) build and style the wagon and its two `wardrobe-*` pickers.

**The Settings skin picker is retired** — `StartMenu.ts` loses 7 lines and nothing else. See F-1081-7.

## Findings

- **F-1081-6 (pre-existing, not this slice, real coverage hole):** `e2e/town-t5-townsfolk.spec.ts` **cannot be collected at all** — importing `../src/town/townsfolk` pulls `src/town/townLayout.ts:53`'s `import.meta.glob` into Playwright's Node-side transform, which throws `TypeError: (intermediate value).glob is not a function` and **aborts the entire run before any test executes**. Reproduced identically on clean main with the wagon fully reverted, so it is not the wagon's. The blast radius is larger than one spec: `e2e/safari-swap.spec.ts`, `e2e/ts-01-plaza-ground.spec.ts`, `e2e/never-trap.spec.ts` and `e2e/ts-04-living-pass.spec.ts` all import `townLayout` **directly**. ➡️ Worth a rung: either move the glob behind a runtime-only module or give these specs a Vite-transforming config. **Until then, any battery that includes one of these five silently reports nothing rather than passing** — the dangerous failure mode, because an aborted run and a green run are easy to confuse in a tail-truncated log.
- **F-1081-7 (open owner question, answered by necessity):** this merge **retires the Settings skin picker** (`StartMenu.ts` −7) in favour of the wagon. That is **F-1079-6**, which s1080 put on the owner's desk as "pull the Settings picker now or let the wagon retire it?" and which has **not been answered**. The wagon's scope requires the retirement, so it merged — but the owner has one word to reverse it, and the veto is cheap while the branch is fresh.
- **F-1081-8 (non-blocking, follows F-1079-5/F-1080-5):** the racks are now real and per-profile, but **the coats still have no cloth** — the shipped batch is `hover4` while the active resolution path requests `hover8`, so both skins fall back to the stock sheet. The wagon makes the wardrobe *reachable*; it does not make the coats *visible*. The recommended fix remains minting hover8 coats as image-EDITs of `assets/raw/char-prospector-sheet-hover8.png` (no owner ruling needed). **Now unblocked** — the two-writers hazard that made s1080 defer the art was this very slice, and it has landed.
