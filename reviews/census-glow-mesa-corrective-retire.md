Net: this census can go from zero FAILs to five and every automated gate stays green; the regression lands in a tracked markdown table that no gate reads. Same family as the known "a green test COUNTER is not a green EXIT CODE" class. **Not fixed here** — turning cells into assertions would red the suite on five known-live defects, which is an owner sequencing call, not a drive-by.
