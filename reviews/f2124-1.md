## What it does

The public agent view could *name* a live seam but never *locate* one. `now.seams` was typed
`{id, active, remaining}`, so an agent wanting a seam's position had exactly one place to look:
`stablePrefix.map.seams` — which publishes the **authored anchor list**. Both surfaces mint the
identical id `gold-seam-N` (`View.ts:244` authored, `HarvestSystem.ts:86` live), so the id-join is
inviting. It is also wrong, because anchor assignment is a Fisher-Yates shuffle
(`HarvestSystem.ts:335-341` via `:428-435`, with `place()` reassigning `anchorIndex`).

This slice adds `x`, `z` and `anchorIndex` to each live seam, rounded exactly the way `map.seams`
rounds — `round(number(...))`, matching `View.ts:245-246` — so the two surfaces are directly
diffable at one precision. Despawned seams publish `null` for all three rather than the world
origin: the `(0,0)` trap the master called out, where "no location" would have been replaced by
"a plausible wrong location right next to the claim". The door doc is corrected in the same
breath — `stablePrefix` now says it locates *authored seam anchors*, and `now` says active seams
carry *their live positions*.

## One thing I checked that turned out fine, recorded so nobody re-opens it

`View.ts:324` computes `const active = node.active === true && anchorIndex !== -1` and publishes
**that** as the seam's `active` field — narrowing an existing published field, not merely adding
new ones. Since `gr-sim.test.mjs` riders destructure `{ active, remaining }`, that looked at first
like a semantic change reaching beyond the slice's additive scope.

**It is inert on every state the sim considers valid.** `HarvestSystem.ts:510` lists
`(node.active && node.anchorIndex < 0)` as a *rejection* condition in its own state validator, so
"active with no anchor" is a state the system already refuses; and `GoldNode.snapshot():249`
always emits `anchorIndex` as an integer, so the `number(node.anchorIndex, -1)` fallback never
fires on well-formed data. The conjunct can therefore only bite on data `HarvestSystem` would
itself reject. It is also **required**: without it, a seam could publish `active: true` with
`x: null`, which is precisely what scope 6's assertion forbids. The runner made the right call
and reported the predicate as the master required.
