## What it does

`import.meta.glob` is a Vite construct. Any spec whose **static** import graph reached
`townLayout` aborted at *collection* with `TypeError: (intermediate value).glob is not a function`
and `Total: 0 tests in 0 files` — an abort that prints **no `N passed` / `N failed` line at all**, so
a gate that tails the log can read it as green. That is why this outranked four broken specs.

The fix moves the glob, the private `TownEraPropManifest` type, and `townEraPropsForOrder` into a new
module, leaving `townLayout` glob-free. The back-reference is `import type`, so no runtime cycle
forms. A new `scripts/town-spec-collection.test.mjs` guard spawns `playwright test --list` over the
four specs and asserts collection succeeds.
