## What it does

`f1417-3` shipped `residueFor({diff, mainText})` — the pure line-level residue function that lets a lane
verdict say *how much* of a held path main has never seen. It shipped with a seven-case guard. s1419 found
that guard had a hole and a shrug:

- **F-1419-1** — `const RICH = 8` (`scripts/lane-residue.mjs:21`) gates the token-set fallback that lets a
  main *superset* line absorb a lane line. Every one of the seven cases exercised that fallback from the
  **permitting** side. Nothing pinned the **refusing** side, which is the destructive direction: lower
  `RICH` and unrelated main text starts absorbing lane lines, a lane that holds real content starts
  reporting zero residue, and a fire resets over it.
- **F-1419-2** — `residueForHeld()` wrapped **both** git reads in one `try`, so *path absent at base* (a
  file the lane created) and *path absent in main* (a LANE-ONLY new file) both collapsed to `UNDECIDABLE`
  — the least informative answer, returned in exactly the case where the lane holds the most.

This slice closes both. Scope 1 adds two cases pinning `RICH` from the refusing side and at the exact
eight-token boundary. Scope 2 splits the two reads: a path absent at base now falls back to a diff against
the empty tree (`4b825dc6…`), so a lane-created file returns `NOT_ABSORBED` with `missing === added`;
`mainText` is read separately and defaults to `''`; and `UNDECIDABLE` retracts to its actual contract —
an **unreadable lane tip**. Both reads now run under `stdio: ['ignore','pipe','ignore']`, ending the bare
`fatal: …` leak to stderr.

  **empty stderr**, because no lane on the current fleet holds a path absent at its base — so the leak

  (`scripts/lane-usable.mjs:44-46`) — read, not assumed, so the injected fake's signature matches the real
  one and `quiet` genuinely reaches the child process. The gap is the *live* arm. Cheap to close whenever a
  lane next holds a lane-created path; not worth manufacturing a lane for.
- 🟡 **F-1420-2 (new, non-blocking, report-don't-fix per scope 5).** `scripts/lane-absorbed-lines.mjs`
