## What it does

`scripts/factory-usage-census.mjs` resolved all of its output paths relative to `process.cwd()`, so a single
invocation with cwd set to a lane worktree wrote the census **into that worktree**, where it became dirty
tracked content reachable from no ref. That is what froze lane-b for ~10 hours and cost the owner-playtest
master `lane-actor-building-clip` 44,562 tokens for zero edits.

The slice derives the main repo root as the parent of `git rev-parse --git-common-dir` resolved against cwd —
which returns the *main* `.git` from every worktree, unlike `--show-toplevel` which returns the worktree — and
anchors all four write sites to it (`CACHE`, `OUT`, and both the read and the write of `usage-history.jsonl`).
When `git` is unavailable it falls back to the previous cwd-relative behaviour rather than throwing, so a
telemetry script never becomes a hard dependency of its callers.
