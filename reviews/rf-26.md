## Findings

### 🔴 F-1088-1 — `test:node-guards` HAS BEEN EXITING 1 SINCE A MERGE EARLIER TODAY, AND NOTHING RECORDED IT

✓ **VERIFIED, and verified on clean main *before* the graft** — the whole point
of running the baseline first. `node scripts/test-ticker-stats.mjs` exits **1**
on main with no slice present:

```
StatsEndpointReadError: ticker-stats: could not read STATS_ENDPOINT from src/encyclopedia/liveStats.ts
    at statsEndpoint (scripts/ticker-stats.mjs:79:11)
```

✓ **Cause read in the code, not guessed.** `src/encyclopedia/liveStats.ts:5` is
now `const STATS_ENDPOINT = gameApiUrl('/api/stats');`, while
`scripts/ticker-stats.mjs:75` matches only a quoted literal:
`/\bconst STATS_ENDPOINT = ['"]([^'"]+)['"]/`. `gameApiUrl(` is not a quote, so
the match fails and the throw is correct behaviour on a parser that has been
outgrown. ✓ **`git log -G` names the commit:** `5b61349e` *"feat: the game
learns to live at agenttown.app/goldrush (release base path + API split law)"*
— merged **earlier today** (the `lane-release-base-path` done-move). So a merge
broke a guard, the guard is not in the drain battery, and **no BACKLOG line
records it** — the F-1086-1 pattern again, one week later, which is precisely
the class rf-26 exists to shrink.

⚠️ **Scope on the impact, stated narrowly rather than alarmingly:** the ticker
**digest** duty (due tomorrow ≥06:00 local) compiles *merges and hashes* and
does **not** need this call; `ticker-stats.mjs --url <endpoint>` also bypasses
`statsEndpoint()` entirely (`:171-173`). So **tomorrow's digest is NOT blocked**
— what is broken is the optional live STATS-LINE garnish.

➡️ **NOT authored as a corrective, deliberately (§7.3).** The one-line fix
(widen the regex) requires deciding **what URL the ticker should now report**,
and that is the release/API-split surface — `gameApiUrl` resolves against the
release base path at runtime, so there is no literal to extract any more. Fixing
it means either teaching the script the base-path rule or having it stop
claiming an endpoint. **That is a small design choice on a surface the owner
owns**, and it sits next to the forbidden deploy work (F-1073-1). **One word
decides it** — see the owner's desk.
