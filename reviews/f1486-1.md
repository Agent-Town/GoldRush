## Findings

### F-1489-1 (non-blocking, FINGERPRINTED **and** control-run) — `vp-02-sprite-animation:405` reds, and it is **not** this slice
`warmed test clip swaps do not grow renderer memory or draw calls` failed on **both** projects:
desktop `:461` **Expected 32 / Received 33**, mobile `:467` **Expected 61 / Received 62**. That is
the exact off-by-one signature of **F-1136-1 / F-1138-6 / F-1146-6** (documented at
`tasks/BACKLOG.md:2724`, `reviews/vp-02b-jumper-slot-repair.md:67`) — same lines, same both-project
pattern, absolute counts drifted upward as the game grew (30/31 → 32/33, 57/58 → 61/62).

⚠️ **The known-red label was NOT sufficient here and was not leaned on.** This slice rewrites the
very hero sheets that test loads, and it roughly **doubles their byte size**, so "causally impossible
for this slice" — the reasoning F-1146-6 was entitled to — is **not available to me**. A slower
decode plausibly pushes first-time uploads past the harness's fixed 160/250 ms waits.

✅ **Discriminated by control run instead.** A detached worktree at **pre-merge main `66bc70545`**
(node_modules symlinked, gate port free, nothing else running) ran the same test isolated at
`--workers=1`: **2 failed, identical test, identical both-project pattern.** The red predates the
merge. Reproduced 3× on the merged tree (full battery, isolated re-run, numbers run) — it is stable,
not noise.

🔻 **But its documented discriminator has decayed, which is the part worth carrying forward.**
F-1146-6's stated premise is *contended RED / quiet GREEN* (`--repeat-each=3` → 3/3 PASS both
projects). On this box today it reds **quiet**, isolated, at `--workers=1`, on **both** the merged
and the pre-merge tree. **The premise that retires this red no longer holds**, so the next fire that
meets it cannot clear it the documented way. Per the F-1460-1 lesson (a red wearing an excused class
label sat unexamined for five fires), this is filed rather than waved through. **Owner/attended
routing not required; a future fire should bisect when the quiet-green property was lost.**

### F-1489-2 (non-blocking, cosmetic-but-misleading) — the gate's failure message still says "301"
`scripts/halo-reextraction-check.mjs` now asserts `264`, but its assertion text reads *"halo residue
differs from the **301** cells held…"* (observed verbatim in ARM 2 above). A future reader chasing
that red is told the wrong denominator by the instrument itself — the same citations-rot class the
law repeatedly names. Left unfixed **in this drain deliberately**: the file is the slice's own
acceptance gate, and editing it in the drain commit would mean the merged artifact differs from the
gated one. Corrective owed, one line.

### Not a finding, recorded because it surprised me
Cured PNGs roughly **double** in bytes (39,393 → 76,948 on the probed cell) — writing RGB into
fully-transparent pixels destroys PNG compressibility. The `asset-diet` budget absorbs it with room
(1.16 MB of a 1.5 MB ceiling) and the build is green, but the headroom is now smaller than it was
and a future cure of the remaining 264 held cells should re-check that ceiling **before** authoring.
