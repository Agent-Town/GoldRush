## What it does
Adds the Cloudflare Pages Functions relay for deterministic-lockstep multiplayer,
per the ratified `specs/multiplayer/README.md` (the relay is a DUMB fan-out; the
sim laws are the netcode). All server-side, **no game `src/` touched**:
- **`functions/api/_multiplayer.ts`** (471L) — the room Durable Object: create-room
  (unguessable 24-hex code), join (code + player name/town, roster broadcast),
  leave/timeout, per-tick ordered input fan-out (batches all players' inputs for
  tick T, broadcasts the bundle), opaque hash-exchange pass-through, snapshot blob
  pass-through for resync/rejoin, room dies 120s after empty. 4 players/room,
  message-size caps, per-connection rate limits, CORS/origins per the AC-01 pattern,
  no persistence beyond room life, no auth v1 (room code IS the key; accounts =
  MP-04's seam). Self-defined types (`DurableObjectNamespaceLike`, `MultiplayerEnv`) —
  **no new deps** per firewall.
- **`functions/api/multiplayer/{create,connect}.ts`** — the route entrypoints.
- **`docs/api-multiplayer.md`** (251L) — the versioned message protocol MP-02 builds against.
- **`scripts/test-multiplayer.mjs`** (354L) + `npm run test:mp` — the headless two-client
  harness (create/join, 200 ticks ordered-identical delivery, hash round-trip,
  drop+rejoin snapshot pull).
- **`package.json`** — `+1` line: `"test:mp": "node scripts/test-multiplayer.mjs"`.
- **`artifacts/multiplayer-relay/test-multiplayer.json`** — the harness's recorded run.

Without a Durable Object binding the endpoints 503 cleanly ("riding together isn't
saddled yet"); the game is unaffected. Binding one-liner for the desk: the worker
expects a DO namespace binding **`MULTIPLAYER_ROOMS`** → the room DO class
(wrangler.toml `[[durable_objects.bindings]]` + a migration), owner/fire applies at deploy.
