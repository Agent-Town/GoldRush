## The roster (6 total; ~1 lane-task each once Town T3 lands)
1. **The Claim** — the standard homestead. EXISTS (the game today). The board's default.
2. **The Claim, Re-surveyed** — identical layout, real elevation (GT-07, owner-ruled A/B). If judged better, becomes the default for NEW runs; the flat original stays selectable + test-canonical.
3. **The Dry Gulch** — no river at all; one spring pond. Twist: water scarcity — sluices only work near the spring (placement puzzle), seams run richer to compensate, no natural barrier so palisade play changes completely. Machinery: terrain gen minus river + a pond feature; sluice placement rule (Balance-additive).
4. **Twin Banks** — build plots on BOTH banks, two fords. Twist: a split homestead — defend two half-bases with one economy; the river is the center of the fight, ford control is everything. Machinery: build-zone manifest + spawn lanes both sides (046's lane constants generalize).
5. **The Night Shift** — dusk falls, then true dark. Twist: sight is the resource — beacon/turret light radii matter, waves come out of the black, dawn ends the run as a victory bell. Machinery: the light rig (m2-02 darker-map + torch glow) ramped over run-time; E3's night-grid PRECURSOR (banked learning). 
6. **The Claim-Jumper Baron** — E1's graduation. Twist: a named outlaw captain leads the deep waves (elite enemy, banner, taunts in ledger voice), unlocked at science-complete; beating him is the story beat that makes the Steamworks megaproject feel EARNED. Machinery: elite-enemy variant (stat block + banner sprite, batch-011 art candidate) — the first named antagonist, warm-satire outlaw per canon (no peoples, ADR-001).
