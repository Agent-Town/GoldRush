# AGENT PLAY — people and their agents, playing together
STATUS: DRAFT 2026-07-22 (attended-authored from the owner's founding promise, stated this day, verbatim: "In Agent Town I always promised that people and their agents could play games together - so with Agents I meant OpenClaw or Hermes or Milady agents. But now Claude Code is already there to handle external sources like a browser. That would be a great feature to have - let your agent play the game alone or together with it to teach it how to play. If the agent could learn from the players runs that would also be awesome. We can harden the harness now with the rehearsal and later potentially publish it as a feature for users.")

- **The Prospector modeled it**: suggest-only → approval-required → trusted-routine — the in-game trust ladder IS the agent-play UX, already owner-approved by play.

## Laws
1. **Agents play by the game's rules**: same input surface as humans (UI events), same information (no sim-internal reads for DECISIONS; diagnostics seams are for telemetry/debug). An agent that cheats teaches nothing.
2. **The tapes are the teaching**: learning-from-player-runs v1 = the SHIPPED playbook shelf — the player's recorded runs become the agent's behavior priors (replay → imitate → blend). No training pipelines in v1; tapes are data.
3. **Ledger honesty**: agent riders are named and marked in rosters/results; the county book never confuses hands.
4. Privacy/safety: BYO-agent protocol is local-first (the user's agent, the user's machine, the user's claim word); publishing anything is owner-gated law.
