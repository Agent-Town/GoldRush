# Security policy

## Supported version

Security fixes target the current `main` branch. Older snapshots and experimental branches are not supported.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting flow from the repository's **Security** tab. If that option is unavailable, contact an Agent Town organization owner privately before sharing technical details.

Include the affected surface, reproduction steps, impact, and any suggested mitigation. Do not include live credentials or personal data in the report.

Please do not open a public issue, publish a proof of concept, or test against production accounts or other players without written permission. We will acknowledge the report privately and coordinate disclosure after a fix is available.
