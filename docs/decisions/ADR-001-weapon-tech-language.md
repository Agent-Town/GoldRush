# ADR-001: Weapon & tech visual language

Date: 2026-07-03 · Decided by: Robin · Status: accepted

Gold Rush weapons and defenses use **frontier-tech**: agent-built rigs, beacons, steam/brass contraptions with agent-tech glow (teal `--at-teal-600` for active systems). No realistic firearms, ever. Violence stays illustrated and readable, never gory (brief §9.2). Over the epoch arc (river → ocean → space, CLAUDE.md §10 M7+), the tech language **develops toward sci-fi frontier-tech** — brass/steam elements progressively give way to sleeker agent-tech as science advances, keeping the "old settlement craft meets new agent collaboration" tension canonical at every epoch. This is canon-compliant (no bend of the 2026-06-01 rule); recorded because it fixes the art-direction trajectory for all combat/defense assets.
