# ADR-003: Agents originate at the Calculating House

Date: 2026-07-07 · Decided by: Robin (owner, explicit — "Yes — full origin story") · Status: accepted

Gold Rush canonically tells the origin of agents in the Agent Town universe: **agents — as the universe knows them — began at Epoch 6's Calculating House**, built by the frontier town from starstone and telegraph craft (specs/epoch-saga/e6-atomic-bundle.md, megaproject section). The Prospector's lineage is therefore the universe's founding line of agents; E7's made-townsfolk, the recruited agents of M6+, and every later agent descend from this room. E10's Ark intelligence is this lineage's furthest child.

Implications: (1) the E6 completion beat is a universe-level story moment — write and art it with that weight (one warm image, no exposition dump); (2) cross-media consistency: any future Agent Town property must respect this origin or supersede it deliberately at the universe level; (3) the "first MADE townsfolk" (E7) gains a name and a portrait as the second canon beat of the arc. Canon guardrails unchanged (warm, illustrated, §9). This is the boldest lore claim the game makes, and it is now load-bearing.
