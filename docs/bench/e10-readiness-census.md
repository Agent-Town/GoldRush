## FINDINGS — EXISTING-DEBT STUBS

### EXISTING DEBT — Ember Shore needs its preserve-contract Static squall socket

Ember Shore calls itself board-launch-only until a preserve-contract Static squall consumer lands, but its data declares neither that mechanic nor the missing dependency and its derived manifest contains only `build_zones`. This is the known post-launch E10 Static/roster class governed by `roster-wiring-e6-e10` and the ratified a/a/a ruling; an attended post-launch master must declare the dependency, boot the real consumer, and derive its actions before admission.

### EXISTING DEBT — Archive World needs the declared restoration consumers

Archive World honestly declares `archive-world-consumers: missing` for its ordered wing restoration, light holds, empty shelf, procgen, objective, and lore unlocks. A generic headless defense would exercise none of them, so the existing content-completion ladder must supply a booted consumer and consumer-derived vocabulary before this contract can receive acceptance seeds.

### EXISTING DEBT — Last Claim remains behind the owner-ruled post-launch finale ladder

The browser v0 proves that a Static preserve loop can run, but the contract still declares `last-claim-objective-consumer: missing`, the headless sim has no Static state, and the manifest cannot express the ruled three verbs or split hands with memory player-only. The ratified a/a/a implementation is explicitly post-launch under `roster-wiring-e6-e10`; this census neither sockets nor re-specifies it.

### EXISTING DEBT — River needs the Charter Press credits-river consumer

River declares `credits-river-consumer: missing`; its generic river and ford rules do not express PAN, surfaced credit flecks, a wave-free run, or a completion event. The existing Charter Press/post-credits work must own that consumer and terminal path before the contract can be admitted, rather than letting GR-SIM's normal wave loop invent the ending.
