# THE LORE WIKI — the single source of truth for everything that is TRUE in this universe
Created 2026-07-09 by owner order: "a story wiki where we keep all this information… how things develop later in the story… all there for agents to know and not make consistency mistakes… the source of truth for characters, their development, institutions, the town, and all the other specific knowledge."

## THE LAWS (binding on every agent — Codex tasks, fires, art generation, beat writing, attended sessions)
1. **READ-BEFORE-WRITE**: any task touching characters, story, institutions, eras, or art of named things MUST read the relevant wiki page first (task masters list it under READ FIRST).
2. **SAME-COMMIT CANON**: a new canon fact (owner ruling, shipped story beat, art decision) lands in the wiki IN THE SAME COMMIT as the thing that established it — the completeness law, applied to truth.
3. **CITED, DATED, SOURCED**: every fact carries its source (owner ruling + date · spec section · ADR). Uncited lore is a proposal, not truth.
4. **THE FUTURE LIVES HERE TOO**: planned arcs (marked PLANNED, with their era) so agents write TOWARD the saga, never against it. Spoiler-grade facts are still facts.
5. **Supersede, never silently edit**: canon changes strike-through the old line with the new ruling's date.
